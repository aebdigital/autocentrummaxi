# Autocentrummaxi Next.js

This is the Next.js version of the Autocentrummaxi website, migrated from the original React SPA. It features high-performance image optimization, modern metadata SEO, and localized routing.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Key Features

- **Next.js 15+**: Latest framework features.
- **Image Optimization**: Using `next/image` for dynamic and static assets.
- **SEO Ready**: Metadata API and JSON-LD schema integration.
- **Tailwind CSS**: Modern utility-first styling.
- **Framer Motion**: Smooth page transitions and animations.
- **Lenis**: Smooth scrolling integration.
